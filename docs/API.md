# API Reference

Base URL: `/api` (e.g. `http://localhost:8000/api` in dev, or `http://localhost/api` through Nginx). Interactive Swagger docs are auto-generated by FastAPI at `/docs` (and ReDoc at `/redoc`) whenever the backend is running - that's the authoritative, always-up-to-date reference; this file is a human-readable summary.

Health/metrics endpoints (`/health`, `/health/database`, `/health/redis`, `/metrics`) live at the **root**, not under `/api`.

## Authentication

| Method | Path | Auth | Description |
|---|---|---|---|
| POST | `/api/auth/login` | none (rate-limited: 10/min/IP) | `{username, password}` -> `{access_token, refresh_token, token_type, user}` |
| POST | `/api/auth/refresh` | none (rate-limited: 20/min/IP) | `{refresh_token}` -> `{access_token, token_type}` |

There is no public self-registration endpoint. Accounts are created by an admin via `POST /api/users`.

## Users

| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/api/users/me` | any signed-in user | Current user's profile |
| PUT | `/api/users/me/password` | any signed-in user | Change own password (requires current password) |
| GET | `/api/users` | admin | List all accounts |
| POST | `/api/users` | admin | Create a team member (role defaults to `viewer`) |
| DELETE | `/api/users/{user_id}` | admin | Remove a team member (blocked if it's the last remaining admin) |
| PUT | `/api/users/{user_id}/password` | admin | Reset a teammate's password |

## Metrics

| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/api/metrics/current` | any signed-in user | Latest CPU/RAM/disk/network snapshot |
| GET | `/api/metrics/overview` | any signed-in user | Health score + current snapshot |
| GET | `/api/metrics/history` | any signed-in user | Historical metric rows |
| WS | `/api/metrics/ws?token=<jwt>` | JWT passed as query param | Live-streamed snapshot, pushed on an interval |

The WebSocket takes its token as a query parameter (not a header) because browsers' native `WebSocket` API cannot set custom headers on the handshake request.

## Alerts

| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/api/alerts` | any signed-in user | List alerts |
| POST | `/api/alerts/{alert_id}/acknowledge` | admin | Acknowledge/resolve an alert |
| POST | `/api/alerts` | admin | Manually create an alert |

## Settings

| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/api/settings` | any signed-in user | Current thresholds/alerting config |
| PUT | `/api/settings` | admin | Update thresholds, cooldown, enable/disable email or Telegram alerts |
| POST | `/api/settings/test-notification` | admin | Send a real test email/Telegram message using the current config |

## System

| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/api/system/info` | any signed-in user | Hostname, platform, uptime, etc. |

## Health & Prometheus (root-level, not under `/api`)

| Method | Path | Description |
|---|---|---|
| GET | `/health` | Overall app health |
| GET | `/health/database` | Real Postgres connectivity check |
| GET | `/health/redis` | Real Redis `PING` - returns 503 + `{"redis": "OFFLINE", ...}` if unreachable, not a hard-coded "ONLINE" |
| GET | `/metrics` | Prometheus text-format metrics, scraped by the `prometheus` service |
